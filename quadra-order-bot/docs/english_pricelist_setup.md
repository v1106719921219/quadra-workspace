# 英語版価格表 自動配信Bot セットアップ手順

## 概要
日本語の価格表を入力すると、自動で英語に翻訳し、顧客ごとの上乗せ金額を反映して、各顧客のDiscordサーバーに配信します。

---

## 仕組み

```
管理サーバー #英語価格表配信
  ↓ 日本語の価格表を投稿
  ↓ AIが自動翻訳 + 顧客ごとの上乗せ金額を反映
  ↓ プレビュー表示 → ✅で配信
  ↓
顧客A #pricelist-english（+¥50で配信）
顧客B #pricelist-english（+¥100で配信）
顧客C #pricelist-english（上乗せなしで配信）
```

---

## セットアップ手順

### 1. 顧客サーバーのセットアップ
顧客サーバーで `/セットアップ 顧客名` を実行すると、以下が自動作成されます：
- #注文はこちらで
- #請求書＆配送ラベル
- #海外代行ラベル
- #プライスリスト
- **#pricelist-english** ← 英語版価格表用

### 2. 顧客側の操作（顧客サーバー #pricelist-english）
1. **「英語版価格表を受け取る」ボタン** を押す → 配信ON
2. **「上乗せ金額を設定」ボタン** を押す → 金額入力画面で上乗せ金額を設定（例: 50 → 全商品+¥50）
3. オフにしたい場合 → もう一度「英語版価格表を受け取る」ボタンを押す

※ 上乗せ金額は顧客がいつでも自分で変更できます

### 3. 管理者側の操作（管理サーバー #英語価格表配信）

#### 価格表の配信
1. #英語価格表配信 に日本語の価格表テキストを投稿
2. 顧客ごとの翻訳プレビューが表示される（上乗せ金額反映済み）
3. 内容を確認して ✅ を押す → 各顧客に配信

#### マークアップ（上乗せ金額）の管理者側での設定
顧客が自分で設定できますが、管理者側でも設定可能です：

| コマンド | 説明 |
|---|---|
| `マークアップ` | 全顧客の上乗せ金額一覧を表示 |
| `マークアップ 顧客名 50` | 顧客の上乗せ金額を+¥50に設定 |
| `マークアップ 顧客名 0` | 上乗せなしに戻す |

---

## 配信例

### 入力（#英語価格表配信に投稿する内容）
```
ポケモンカード 151 BOX ¥10,000
イーブイヒーローズ BOX ¥8,000
レイジングサーフ BOX ¥5,000
```

### 出力例（顧客Aの #pricelist-english、上乗せ+¥50の場合）
```
・Pokemon Card 151 BOX - ¥10,050
・Eevee Heroes BOX - ¥8,050
・Raging Surf BOX - ¥5,050
```

### 出力例（顧客Bの #pricelist-english、上乗せなしの場合）
```
・Pokemon Card 151 BOX - ¥10,000
・Eevee Heroes BOX - ¥8,000
・Raging Surf BOX - ¥5,000
```

---

## 注意事項
- 配信前に必ずプレビューが表示されます。✅を押さない限り配信されません
- 顧客が「英語版価格表を受け取る」ボタンを押していない場合、その顧客には配信されません
- 上乗せ金額は全商品に一律で適用されます（商品ごとの個別設定は不可）
- 翻訳はAI（Claude）による自動翻訳です。商品名と価格のみ抽出されます
