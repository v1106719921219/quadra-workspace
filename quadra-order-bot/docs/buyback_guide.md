# 買取スクエア（トレカ買取申込システム）操作ガイド

## システム概要
買取スクエアはトレーディングカードの買取申込から検品・振込までを管理するシステムです。
東京（kaitorisquare.com）と千葉（chiba.kaitorisquare.com）の2拠点で運営しています。

---

## お客様向けページ

### トップページ（/）
- 「買取を申し込む」ボタン → 申込フォームへ
- 「買取価格を見る」ボタン → 価格表へ
- 4ステップの流れ: 商品選択 → 情報入力 → 発送 → 振込

### 買取価格表（/prices）
- カテゴリ・サブカテゴリで絞り込み可能
- キーワード検索対応
- 価格が0円の商品や非表示設定の商品は表示されません

### 買取申込フォーム（/apply）3ステップ

#### ステップ1: 商品選択
- **事務所選択**: 発送先の事務所を選択（住所が表示される）
- **発送日**: いつ発送するか入力（「今日」ボタンで当日設定）
- **AI自動入力機能**: LINEの注文テキストをペースト → AIが商品を自動マッチング
  - 例: 「イーブイヒーローズ 3箱」とペーストすると自動でカートに追加
- **商品検索**: カテゴリ・サブカテゴリで絞り込み、テキスト検索も可能
- **カート**: 右サイドバー（モバイルは下部固定バー）に選択商品・数量・合計表示

#### ステップ2: お客様情報
- **リピーター検索**: メールアドレスで過去の申込情報を自動入力
- 入力項目: 氏名、LINE名、生年月日、職業、メール、電話、都道府県、住所
- 適格請求書発行事業者かどうか（該当する場合は事業者番号入力）
- 本人確認方法の選択
- 振込口座情報: 銀行名、支店名、口座種別（普通/当座）、口座番号、口座名義（カタカナ）

#### ステップ3: 確認
- カート内容・お客様情報・発送先を確認して送信

### 申込完了ページ（/apply/complete）
- 注文番号表示（例: BB-20260310-001）
- 発送先住所の表示
- **追跡番号入力**: すぐに入力するか、後から入力可能。複数追跡番号対応
- **商品編集**: ステータスが「申込」の間は数量変更・商品追加・削除が可能

### 追跡ページ（/tracking）
- 注文番号を入力してステータス確認

### ご利用ガイド（/guide）
- 申込〜振込までの7ステップフロー
- 注意事項: 発送要件、必要書類（初回は住民票等、2回目以降は不要）、禁止事項（傷・折れ・偽造カード等）、梱包方法

## 管理画面

### ダッシュボード（/admin）
4つのサマリーカード:
- 本日の申込件数
- 処理中の件数（完了・キャンセル以外）
- 検品待ちの件数
- 本日の振込額

### 注文管理（/admin/orders）
- **検索**: 注文番号・顧客名・メールで検索
- **ステータスフィルター**: ドロップダウンで絞り込み
- **ページネーション**: 1ページ20件

#### 注文ステータス
申込 → 発送済 → 検品完了 → 振込済（キャンセルは任意のステップから遷移可）

#### CSV出力機能
- **古物台帳CSV**: 全注文詳細（商品ごとに1行）
- **月次集計CSV**: 日別・注文別の集計
- 月を選択してエクスポート

### 注文詳細（/admin/orders/[id]）
- 注文情報・ステータス・顧客情報の表示
- **注文明細テーブル**: 商品名・単価・数量
- **ステータス履歴**: タイムライン形式で全変更記録
- **メモ欄**: 内部用メモの編集
- **追跡番号**: 確認・追加
- **事務所変更**: 発送先事務所の変更
- **重複検知**: 同じ顧客の他の注文を表示
- **アクション**: 注文削除、検品PDF、ステータス変更

### 検品（/admin/orders/[id]/inspect）
- 「発送済」ステータスの注文のみアクセス可能
- 各商品の検品数量・検品価格・返品数量を入力
- 検品中に商品の追加・削除可能
- 割引額の入力
- 検品メモの記入
- 到着日入力（千葉のみ）
- 保存で「検品完了」に遷移

### 支払い管理（/admin/payments）
2つのタブ:
1. **検品完了**: 振込待ちの注文一覧。チェックボックスで振込済みマーク。一括処理対応
2. **発送済**: 検品待ちの注文一覧

### 到着予定（/admin/arrival-schedule）
- 事務所ごとに到着予定日でグルーピング
- 本日到着予定は青バッジ、遅延可能性は赤バッジ
- 各日付グループに商品名・数量・合計数表示

### 商品管理（/admin/products）
- **美品査定設定**: ON/OFFトグルでAR美品査定機能の有効/無効
- **インライン価格編集**: 価格をクリックして直接編集、Enterで保存
- **表示/非表示切替**: バッジをクリックして価格表への表示を切替
- **並び順管理**: カテゴリ内の上下矢印で並び替え
- **CSV出力**: 現在のフィルター結果をCSVダウンロード
- **CSVインポート**: CSV形式で一括登録・更新。プレビュー付き
- **商品作成/編集**: ダイアログで商品名・カテゴリ・サブカテゴリ・価格を入力

### 一括価格更新（/admin/products/bulk-update）
- CSVまたは手動入力で大規模な価格更新
- 適用前にプレビュー表示

### 価格履歴（/admin/products/price-history）
- 価格変更の履歴を確認（いつ・いくらから変更されたか）

### カテゴリ管理（/admin/categories）
- カテゴリの作成・編集・削除
- 表示順・有効/無効の管理

### 事務所管理（/admin/offices）
- 事務所の住所・電話番号等の編集
- 有効/無効の切替

### スタッフ管理（/admin/staff）
- 管理画面にアクセスできるユーザーの管理
- ロール（admin/staff）の設定

## 特殊機能

### AI自動入力
1. 申込フォームのステップ1で「AIで自動入力」カードを使用
2. LINEのテキスト（例: 「イーブイヒーローズ 3箱\n25thアニバーサリー 2箱」）をペースト
3. Claude AIが商品名を解析し、データベースの商品と自動マッチング
4. マッチした商品がカートに自動追加
5. 「シュリなし」「シュリ無し」は「シュリンク無し」サブカテゴリとして認識

### AR美品査定
- AR（美品）商品がカートに追加されると、査定方法の選択ダイアログが表示
- **最低保証**: 保証された最低価格で買取
- **美品査定希望**: 状態に応じた査定価格（高くなる可能性あり）
- 管理画面の商品ページでON/OFF切替可能

### リピーター認識
- 申込フォームのステップ2でメールアドレスを入力すると、過去の申込情報を自動入力
- 氏名・住所・口座情報などが自動補完されるため、リピーターの入力負担を軽減

## 管理画面の日々の作業

**毎日:**
1. ダッシュボードで本日の申込・処理中件数を確認
2. 新規注文の確認（/admin/orders）
3. 到着予定の確認（/admin/arrival-schedule）

**商品到着時:**
1. 該当注文を「発送済」から検品ページへ
2. 検品数量・検品価格を入力
3. 問題があれば検品メモに記録
4. 「検品完了」で保存

**振込処理:**
1. 支払い管理ページ（/admin/payments）で「検品完了」タブ確認
2. チェックボックスで振込済みをマーク（一括処理可能）
3. ステータスが「振込済」に自動更新

**定期:**
- 商品の価格更新（インライン編集 or 一括更新）
- 月次CSV出力（古物台帳・月次集計）
- カテゴリ・サブカテゴリの整理

## よくある質問

**Q: お客様が申込後に商品を変更したい**
A: ステータスが「申込」の間は、完了ページ（/apply/complete）から数量変更・商品追加・削除が可能です。

**Q: 検品で数量が申込と異なる場合**
A: 検品ページで実際の検品数量を入力してください。返品数量も指定可能です。

**Q: 同じお客様から複数回申込があった**
A: 注文詳細ページで同じ顧客の他の注文が「重複検知」として表示されます。

**Q: 価格表に商品が表示されない**
A: 商品管理で「表示/非表示」バッジを確認してください。非表示設定または価格0円の商品は価格表に表示されません。

**Q: CSVインポートのフォーマットは？**
A: カテゴリ,サブカテゴリ,商品名,買取価格 の形式です。プレビューでエラー確認後に適用されます。

**Q: AR美品査定を有効/無効にしたい**
A: 商品管理ページ（/admin/products）上部の「美品査定受付」トグルで切り替えてください。
