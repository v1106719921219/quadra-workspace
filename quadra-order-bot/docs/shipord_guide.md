# ShipOrd（受注管理システム）操作ガイド

## システム概要
ShipOrdは受注〜出荷〜配送追跡の一連の流れを一元管理するシステムです。

## メインメニュー（サイドバー）

| メニュー | パス | 説明 |
|----------|------|------|
| ダッシュボード | `/dashboard` | KPI・本日の売上・最近の注文 |
| 注文 | `/orders` | 注文一覧・検索・フィルター |
| 顧客 | `/customers` | 顧客マスター管理 |
| 出荷 | `/shipping` | 配送管理・梱包スタッフ割当 |
| 商品 | `/products` | 商品マスター・CSVインポート/エクスポート |
| 設定 | `/settings` | 会社情報・梱包担当者・アカウント管理 |

## 注文管理

### 注文一覧（/orders）
- **日付フィルター**: デフォルト本日。前日・翌日ボタンで移動。「期間指定」で範囲検索も可能
- **注文種別タブ**: すべて / 通常 / 予約
- **未入金フィルター**: 右側ボタンで未払い注文のみ表示
- **検索**: 注文番号・顧客名で検索可能

### 注文ステータス
受注 → 請求書送付済 → 入金確認済 → 出荷準備中 → 出荷完了（キャンセルは任意のステップから遷移可）

### 新規注文作成（/orders/new）
1. **顧客選択**: コンボボックスで既存顧客を選択。見つからなければ「新規顧客作成」ボタン
2. **注文種別**: 通常 or 予約
3. **請求先情報**: 名前・電話・郵便番号・住所
4. **発送先情報**: 顧客の住所録から選択 or 新規入力
5. **注文明細**: 商品をオートコンプリートで検索して追加。数量・単価入力
6. **LINEチャット解析**（オプション）: LINEチャットをペースト → AIが商品を自動抽出
7. **出荷割当**（オプション）: 事務所・配送業者・配送種別・配達日時・個数を指定
8. **送料・割引**: 送料は個数×1,100円/個口で自動計算。割引額は手動入力
9. 「作成」ボタンで保存

### 注文詳細（/orders/[id]）

#### 基本情報
- 注文番号・顧客名・会社名・ステータス・作成日時
- 請求先カード（表示のみ）
- 発送先カード（「発送先変更」ボタンで編集可能）

#### 注文明細
- 商品名・数量・単価・小計の表
- 「+」ボタンで商品追加
- 各行に削除ボタン（出荷割当前のみ削除可能）
- 送料（編集可能）・割引・合計の表示
- 請求書確認チェックボックス

#### 出荷割当
- **未割当アラート**: 割当されていない商品がある場合、黄色アラート表示
- **出荷割当の追加**: 事務所・配送種別・配送業者・配達日・時間帯・個数・割当商品を指定
- 各出荷割当カードに: ラベルアップロード、スタッフ割当ドロップダウン、注記テキストエリア、削除ボタン

#### 配送ラベル
- ドラッグ&ドロップ or ファイル選択でアップロード（画像・PDF対応）
- キャリア名・追跡番号を自動抽出
- 追跡URL自動生成（ヤマト・佐川・日本郵便対応）
- 「Discordに送信」ボタンで顧客に通知

#### 注文アクション（右上）
- **ステータス変更**: ドロップダウンで選択
- **請求書**: PDF生成・ダウンロード
- **請求書送信**: Discord Webhookで顧客に送信
- **削除**: 確認ダイアログ付き

## 顧客管理

### 顧客一覧（/customers）
- 検索ボックスで顧客名検索
- 「新規顧客登録」ボタン

### 新規顧客作成（/customers/new）
入力項目: 名前（必須）、会社名、メール、電話番号、郵便番号、住所、Discord Webhook URL（請求書送信用）、Invoice Webhook URL、LineWorks ID、備考

### 顧客編集（/customers/[id]）
- 基本情報の編集フォーム
- **ラベルURLコピーボタン**（右上）: 顧客用のラベル撮影ページURL
- **住所録管理**: 複数の配送先住所を登録可能。ラベル・住所・デフォルト設定・配達時間帯を管理

---

## 商品管理（/products）

- **CSV エクスポート**: 全商品をCSVダウンロード
- **CSV インポート**: CSVから一括登録
- **新規商品作成**: ダイアログで名前・SKU・事務所・価格を入力
- **インライン編集**: テーブル上のペンシルアイコンから直接編集。チェック・バツボタンで確定/キャンセル

---

## 出荷管理（/shipping）

### 出荷一覧
- **日付選択**: デフォルト本日。前日・翌日ボタンで移動
- **注文種別フィルター**: すべて / 通常 / 予約
- **事務所タブ**: すべて / 各事務所ごと

### 集荷予約サマリー
- 各事務所ごとに個口数集計
- 配送業者ごとの個口数
- 本日分の「集荷予約済み」チェックボックス

### 出荷テーブル
注文番号、顧客名、配送業者、配達日、個数、スタッフ（梱包担当者選択）、配送ラベル、追跡番号、住所、備考、ラベル作成チェック、Discord転送ボタン

### 撮影モード（/shipping/capture）
スマートフォンで配送ラベルを撮影・確認する簡易モード。事務所フィルター対応

## 設定（/settings）

### 会社情報タブ
会社名・代表者名・メール・電話番号・住所

担当者名・事務所・ステータスの管理。新規追加可能

スタッフのメール・ロール・ステータス管理。アカウント削除可能

## 日々の作業フロー（推奨）

**朝:**
1. ダッシュボードで本日の売上・注文数確認
2. 注文一覧で新規注文確認

**午前:**
1. 新規注文の登録
2. 出荷割当の作成（配送日・業者指定）

**午後:**
1. 出荷管理で当日の配送確認
2. 梱包担当者の割当
3. ラベル画像アップロード
4. Discordで顧客に通知

**夕方:**
1. ステータスの更新
2. 未送信の請求書確認
3. 入金確認

## よくある質問

**Q: 新規注文作成時に顧客が見つからない**
A: 顧客一覧ページで先に新規作成するか、注文作成フォーム内の「新規顧客作成」ボタンを使用してください。

**Q: 出荷割当後に事務所を変更したい**
A: スタッフ割当（梱包担当者の選択）を解除してから変更してください。または出荷割当を削除して新規作成してください。

**Q: 請求書がDiscordに送信されない**
A: 顧客のDiscord Webhook URLが設定されているか確認してください。

**Q: ラベルの追跡URLが生成されない**
A: 配送業者名が正確に登録されているか（ヤマト運輸、佐川急便、日本郵便等）、追跡番号が正しく入力されているか確認してください。

**Q: 出荷割当済みの商品が削除できない**
A: 先に出荷割当を削除してから商品を削除してください。

**Q: 注文の発送先住所を変更したい**
A: 注文詳細ページの発送先カードにある「発送先変更」ボタンから編集できます。
